# Solucion en blanco (empty .sln) de Base
**Solucion .NET vacia** (en blanco) generada con **Visual Studio 2022** (VS 2022) que puede abrirse con version siguiente de VS.

## Publico Objetivo
Estudiantes de la asignatura electiva Tecnologias de Desarrollo de Software IDE (TDS) de UTN Rosario que no pudieran instalar la version 2022 de VS y necesiten una solucion vacia (empty solution) para iniciar sus desarrollos.

## Fundamento
Dado que en Laboratorio de UTN Rosario contamos con la version 2022 de VS y dado que la siguiente version de VS (2026) genera un archivo de solucion diferente con extension .slnx (en lugar de .sln que generan los VS desde 2022 hacia atras) se deja a disposicion del estudiante esta solucion en blanco/vacia (empty solution) para que pueda tomar de base e iniciar sus desarrollos en caso que cuente con alguna version superior a VS.
